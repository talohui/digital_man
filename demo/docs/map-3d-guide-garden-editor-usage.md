# /map-3d-guide-c 图形化园林编辑器使用说明

## 1. 打开方式

普通展示页：

```text
/map-3d-guide-c
```

园林编辑模式：

```text
/map-3d-guide-c?debugGarden=1
```

只有带 `debugGarden=1` 时才显示图形化园林编辑器。普通游客页面不会显示编辑面板，也不会显示 zone / keepout 的编辑边界和顶点。

## 2. 编辑器定位

`debugGarden` 已从早期工程调试面板收敛为 5 步向导式园林配置工作台，用于人工校准 `/map-3d-guide-c` 的 GLB 树群、灌木和山石资产。

编辑模式下页面会隐藏普通导览 UI 中容易干扰校准的游客信息，只保留：

- 3D 园林导览牌。
- 3D 视角切换卡片。
- `debugGarden` 工作台。
- 返回普通页按钮。

这样可以把校准重点放在腾讯地图坐标、路线、POI、树群和编辑对象之间的空间关系上。

## 3. 5 步工作台

当前工作台步骤为：

1. 禁放区。
2. 放树区。
3. 生成预览。
4. 应用 GLB。
5. 导出配置。

工作台顶部会显示当前数据来源：

- `默认航拍参考布局`：使用源码内置的稳定默认配置。
- `localStorage 草稿`：使用浏览器本地保存的编辑草稿。

如果出现旧草稿污染，可在第 5 步使用“清空本地草稿”或“重置为默认航拍参考布局”，不需要打开浏览器 DevTools 手动删除 `localStorage`。

## 4. 第 1 步：禁放区

先画 keepout 禁放区，用来约束后续自动生成树群的位置。

建议优先圈出：

- 金色主路线附近。
- 南门、胜境广场、九龙灌浴、佛手广场等开阔广场。
- 梵宫、五印坛城、祥符禅寺等建筑主体。
- 停车场、主道路、现代街区。
- 当前站点、下一站、终点和重要 POI marker 周围。

操作方式：

1. 点击“新建禁放区”。
2. 在地图上逐点点击，形成多边形顶点。
3. 双击地图或点击“完成多边形”完成绘制。
4. 选中某个 keepout 后，可在地图上拖拽顶点微调。

显示规则：

- 默认不显示所有 keepout 的边界和底色。
- 只有选中某个 keepout 后，才显示红棕色虚线边框和可拖拽顶点。
- 选中区域也不显示大面积底色，避免覆盖路线、POI 和地图细节。

## 5. 第 2 步：放树区

再画 vegetation 放树区，用于定义可生成树群、灌木、山石的区域。

推荐区域：

- 灵山大佛背后和两侧山林。
- 中轴线两侧林带。
- 祥符禅寺周边边缘绿化。
- 梵宫外围绿化。
- 五印坛城水体边缘。
- 出口附近低密度收束绿化。

每个 vegetation zone 可配置：

```text
name
kind: forest / axis_grove / water_edge / node_green
density
assetPool
assetRatios
minScale / maxScale
minHeight / maxHeight
opacity
priority
visible
```

显示规则：

- 默认不显示所有 vegetation zone 的边界和底色。
- 只有选中某个 zone 后，才显示青绿色边框和可拖拽顶点。
- 选中区域仍不显示大面积填充色。

## 6. 第 3 步：生成预览

点击“生成预览点”后，系统会根据 vegetation zone、keepout zone、路线和站点位置生成轻量预览点。

预览点只是位置检查，不是真实 GLB 模型。生成后重点检查：

- 是否落在广场中心。
- 是否压住金色主路线。
- 是否落在建筑屋顶上。
- 是否遮挡当前站点、下一站或终点 marker。
- 大佛背后和中轴两侧是否形成连续林带。
- 水边是否以低矮灌木为主。

如果预览不合理，应先调整 zone / keepout，再重新生成预览。

## 7. 第 4 步：应用 GLB

点击“应用 GLB”会把预览点转换为真实 GLB 树、灌木、山石模型。

当前资产点默认显示 GLB 模型，但不显示编辑点。只有选中某个资产点后，才显示可拖拽编辑标记。

单个资产支持：

- 地图拖拽修改位置。
- 面板中修改 `scale`。
- 面板中修改 `height`。
- 面板中修改 `yaw` / rotation。
- 面板中修改 `opacity`、`visible`、`priority` 等字段。

注意：拖拽或输入修改后，必须点击“保存当前资产修改”才会写入本地草稿。未保存的编辑只停留在当前面板草稿状态。

删除资产点时会有二次确认，避免误删。

## 8. 第 5 步：导出配置

导出区支持：

- 复制完整配置。
- 仅复制 assets。
- 保存到本地。
- 清空本地草稿。
- 重置为默认航拍参考布局。
- 复制调试摘要。

推荐在人工校准满意后使用“复制完整配置”，把结果交给 Codex 整理进 `src/data/lingshanMap3DGardenAssets.ts`。如果只调整了资产点，也可以使用“仅复制 assets”。

zone / keepout / asset 删除均有二次确认。清空本地草稿和重置默认会清理 debugGarden 相关 `localStorage`，并恢复源码默认布局。

## 9. 批量校准能力

高级设置中支持按以下条件筛选资产：

- zone。
- kind。
- priority。
- visible。

对当前筛选结果可批量执行：

- 缩放。
- height 调整。
- opacity 调整。
- 经纬度偏移。
- 显示筛选资产。
- 隐藏筛选资产。

这些能力用于快速校准一片林带或某类资产，不建议在未确认筛选范围时直接批量修改。

## 10. 与运行时诊断配合

如需观察加载耗时，可打开：

```text
/map-3d-guide-c?debugGarden=1&debugPerf=1
```

这会同时显示 5 步工作台和运行时诊断面板。诊断面板用于查看 map 初始化、路线 / POI overlay 创建、GLB 批次、失败和重复 URL，不改变园林配置数据。

## 11. 注意事项

- 先画禁放区，再画放树区。
- 广场中心要留白。
- 建筑主体上不要放树。
- 主路线、当前位置、下一站、终点周围要留白。
- 大佛背后可以最密。
- 中轴两侧适合形成连续林带。
- 水边适合低矮灌木，不适合高树密堆。
- 山石只作为边界点缀，不应成为主视觉。
- 生成 GLB 前先看预览点。
- 单个资产拖动后必须点击“保存当前资产修改”。
- 调试完成后一定要导出配置并固化到源码，不能依赖浏览器 localStorage 作为正式数据来源。
