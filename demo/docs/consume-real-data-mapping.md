## 4. 正式商品中心接口要求

正式接入时，后端商品中心应覆盖静态目录并至少返回：

```ts
type ScenicProduct = {
  productId: string
  category: 'food' | 'shopping' | 'transport' | 'entertainment'
  name: string
  description: string
  location: { poiId?: string; label: string }
  saleMode: 'paid' | 'included' | 'free_on_site' | 'information_only'
  price?: { amount: number; currency: 'CNY'; unitLabel: string }
  availability: 'available' | 'sold_out' | 'paused' | 'booking_required'
  inventory?: number
  optionGroups: Array<{
    optionGroupId: string
    label: string
    required: boolean
    options: Array<{ optionId: string; label: string; priceDelta?: number }>
  }>
  serviceWindow?: { startAt: string; endAt: string }
  performanceSessions?: Array<{ sessionId: string; startAt: string; remaining?: number }>
  sourceUpdatedAt: string
}
```

前端规则：

1. 只有 `saleMode === 'paid'` 且存在有效 `price`、`availability === 'available'` 时允许加入购物车。
2. `included`、`free_on_site` 和 `information_only` 只能显示“查看信息”，不得进入模拟或真实支付。
3. 价格、库存、营业时间、场次和预约余量必须以接口为准；本地资料参考值不能覆盖接口结果。
4. 下单时需保存 SKU/规格快照，历史订单不随商品中心后续变更而改变。
5. 《灵山吉祥颂》是否仍为门票内含、具体场次和入场规则应在每次打开详情时刷新。

## 5. B 端商品管理建议

B 端商品管理需要支持：

- 商品基础信息、分类、关联 POI、计价单位和展示图片；
- 付费、门票内含、现场免费、仅信息四种销售模式；
- SKU/规格、库存、上下架、营业时段和预约场次；
- 价格生效时间、节假日价格与变更审计；
- 免费服务和门票内含项目的独立状态管理，避免被错误加入购物车；
- 数据来源、最后核验人、最后核验时间和景区公告链接；
- 小灵推荐所需的适用人群、路线位置、体力强度、推荐理由素材等结构化字段。
