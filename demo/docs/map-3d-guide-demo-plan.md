# 灵山胜境真实 3D 地图导览 Demo 方案

## 1. 页面目标

`/map-3d-guide` 是独立于 `/map` 和 `/scenic-3d-map` 的第一版真实 3D 地图导览 demo。

它使用腾讯地图 JavaScript API GL 作为真实地理底座，结合项目已有的路线、POI、routeGeometry 和 GLB 模型配置，演示“真实地图 + 3D 倾斜视角 + 风格化导览 UI + 模拟定位 + 偏航重规划”的产品方向。

## 2. 页面边界

本页面不替代现有页面：

- `/map` 保持现有真实地图增强模式和调试工具。
- `/scenic-3d-map` 保持 Three.js 沉浸式文化沙盘。
- `/three-preview` 保持 3D 资产测试页。

`/map-3d-guide` 是独立 demo，用于验证后续真实游客导航主线。

## 3. 当前实现范围

第一版固定演示历史文化路线：

- 路线：`historical_culture`。
- 主路线：优先使用现有 `lingshanRouteGeometries` 中的候选路线。
- 地图：腾讯地图 GL JS，默认进入倾斜 3D 视角。
- UI：高级东方、水墨青绿、佛教金色、宣纸雾化风格。
- 主路线：金色导览线。
- 当前位置：风格化模拟位置 Marker。
- 核心 POI：路线站点 Marker 和底部 POI 列表。
- 偏航：点击“模拟偏航”后移动到路线外。
- 重规划：偏航后调用腾讯 walking route，生成临时路线到下一站。
- 模型：通过“显示 3D 景点模型 Beta”尝试加载 `giant_buddha` GLB 覆盖物。

## 4. 交互设计

### 顶部标题区

- 显示历史文化路线。
- 提供跳转 `/map` 和 `/scenic-3d-map` 的入口。

### 底部控制栏

## 5. 腾讯 API 调用边界

页面加载时不调用腾讯 walking route。

只有点击“模拟偏航”后，才调用一次 `buildWalkingRoute([偏航位置, 下一站位置])`，用于模拟真实偏航后的重规划流程。

如果请求失败或返回 fallback，页面仍保持可用，并显示兜底提示和临时线。

## 6. GLB 模型 Beta

页面复用 `lingshanMapModelOverlays.ts`：

- 当前至少尝试加载 `giant_buddha`。
- 模型开关默认关闭。
- 模型加载失败不影响地图导览。
- 本页面不提供调参控件，模型校准仍在 `/map?debugGltfModel=1` 完成。

## 7. 艺术化主视觉层

当前 `/map-3d-guide` 的视觉策略已经从“腾讯地图加滤镜”调整为“腾讯地图坐标底座 + 地图锚定水墨导览元素”。

腾讯地图继续负责：

- 真实经纬度底座。
- 腾讯 3D 相机。
- POI 和路线锚点。
- walking route 重规划。
- GLB 模型覆盖物锚定。

页面风格化导览层负责：

- 沿历史文化路线铺陈的水墨树木、桥、水体、院落、石阶、山石、云雾、莲花和光点。
- 宣纸纹理。
- 核心游线区域柔光和金色主路线。
- 当前站点、下一站和终点的地图锚定标签。
- 模拟偏航后，重规划路线附近的青蓝水墨提示。

该层不使用固定屏幕大贴图，不宣称精确还原所有建筑和地形，而是为真实坐标导览提供灵山定制艺术表达。第一版只覆盖历史文化路线沿线核心区域，不覆盖全园区。

### 路线唤醒机制

水墨装饰点带有 `routeIndex`，随着模拟定位沿 `historical_culture` 路线前进逐步显现。已到达区域的装饰透明度和尺寸提高，未到达区域保持隐藏或低透明，形成“导览路径唤醒地图”的效果。

当触发模拟偏航并生成腾讯 walking 重规划路线时，主线装饰会略微降透明，重规划路线附近会出现青蓝云雾提示。重规划线本身仍由腾讯地图坐标路径绘制，保持真实地理绑定。

### debugDecor 调试模式

打开 `/map-3d-guide?debugDecor=1` 后，会显示水墨装饰调试面板：

- 选择任一装饰点。
- 调整类型、经纬度、缩放、旋转、透明度、显现索引和层级。
- 调整结果自动保存到 `localStorage`。
- 下次打开 debug 模式自动恢复。
- 支持复制 TS 配置片段，后续可整理为 `lingshanMapDecorOverlays.ts`。

## 8. 视觉素材说明

本阶段没有引入外部图片或第三方视觉素材，也没有使用许可证不明确的素材。

页面风格化效果由 CSS 渐变、内联 SVG、半透明覆盖层、SVG data URL Marker 和 UI 面板实现。水墨树木、水体、院落、桥、山石、云雾、莲花和光点均为项目内代码生成的原创图形。

素材记录见 `docs/map-3d-guide-asset-licenses.md`。

## 8.1 /map-3d-guide-c：沉稳 3D 园林资产版

`/map-3d-guide-c` 是新的 3D 园林资产视觉原型，用于验证比 A/B PNG 贴片更沉稳的低模园林沙盘方向。

它复用 `/map-3d-guide` 的腾讯地图初始化、`mapStyleId: 'style1'`、历史文化路线、模拟定位、模拟偏航、腾讯 walking route 重规划和 GLB 模型 Beta 逻辑，但禁用 PNG / SVG 路线装饰贴片，改为通过腾讯 `TMap.model.GLTFModel` 加载低模 GLB 园林资产。

当前 C 版使用项目自制低模 fallback GLB：

- 树群。
- 山石。
- 石阶。
- 院墙。
- 小桥。
- 寺庙屋顶。
- 莲台。
- 法轮。
- 香炉。

这些资产全部绑定经纬度，随腾讯地图缩放、旋转和平移移动，不使用固定屏幕大贴图。

### debugGarden

访问 `/map-3d-guide-c?debugGarden=1` 可打开 3D 园林资产调试面板，支持调整：

- 经纬度。
- scale。
- height。
- yaw。
- visible。
- priority。
- routeFraction。

调试结果保存到 localStorage，并支持复制 TS 配置片段，后续可整理为稳定配置。

## 9. 验收点

- `/map-3d-guide` 可打开。
- 页面默认是腾讯地图倾斜 3D 视角。
- 页面不是裸腾讯地图，有明显灵山风格。
- 页面主视觉不只是腾讯地图滤镜，而是有地图锚定水墨树木、水体、院落、桥、山石、云雾、莲花、光点、金色游线和 POI 立牌。
- 水墨装饰随模拟进度逐步显现。
- `/map-3d-guide?debugDecor=1` 可调试装饰点并导出配置。
- `/map-3d-guide-c` 可打开，并能看到沉稳低模 3D 园林资产沿历史文化路线布置。
- `/map-3d-guide-c?debugGarden=1` 可调试 3D 园林资产并导出配置。
- 历史文化路线、当前位置、下一站和终点清楚。
- 模拟前进可更新当前位置和进度。
- 模拟偏航会调用腾讯 walking route 到下一站。
- 临时重规划路线能显示。
- GLB 模型 Beta 开关可用且失败不崩溃。
- `/map`、`/map?debugGltfModel=1`、`/scenic-3d-map` 不受影响。
