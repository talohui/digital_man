# /map-3d-guide A/B 视觉原型方案

## 1. 目标

本阶段为真实 3D 导览地图新增两个独立视觉原型页面：

- `/map-3d-guide-a`：少量高质量素材反复组合，统一、克制、路线优先。
- `/map-3d-guide-b`：更多素材密集铺陈，视觉冲击更强，偏数字沙盘。

两个原型都复用现有 `/map-3d-guide` 的腾讯地图 3D 底座、`mapStyleId: 'style1'`、历史文化路线、模拟定位、模拟前进、模拟偏航、腾讯 walking route 重规划、重规划路线和 GLB 模型 Beta。现有 `/map-3d-guide` 保持不变。

## 2. 子 agent 辩论结论

### A：少量高质量素材

A 版主张把首屏注意力留给真实地图和金色路线。素材不追求数量，而是用树木、山石、莲花、佛光、院落等少量元素反复组合。验收标准是当前站点、下一站、当前位置和主路线在 3 秒内可识别。

### B：高密度视觉冲击

B 版主张沿历史文化路线铺陈更多树群、水系、院落、山石、云雾、莲花和光点，在关键节点形成“到站爆点”。但所有素材仍必须地图坐标锚定，不能回到固定大贴图。

### C：性能、许可证和工程风险

C 版审查认为 A/B 应复用同一套地图和导航逻辑，只隔离视觉配置。不要新增第二个地图实例，不要默认加载大 GLB，不要提交许可证不清的素材。素材 marker 数量应受控，路线、当前位置、下一站和重规划线层级必须高于装饰。

## 3. A 版设计

`/map-3d-guide-a` 定位为“青绿佛境精品导览”：

- 单屏装饰数量控制在少量锚点。
- 使用 Kenney Foliage Pack 的树木 / 山石 PNG 和 OpenGameArt Lotus Flowers 的莲花 PNG。
- 佛光和院落仍使用项目自绘 SVG，保证风格统一。
- UI 更克制，强调导览路线和关键站点。
- 装饰通过 `TMap.MultiMarker` 经纬度锚定，随地图缩放、旋转、平移。
- 装饰显现仍使用路线进度：未到达区域不显示，接近当前进度后逐步出现。

## 4. B 版设计

B 版定位为“路线唤醒灵山画卷”，在 A 版基础上提高装饰密度：

- 沿历史文化路线布置 32 个地图锚定装饰点。
- 关键节点周边增加树群、莲花、佛光、院落、云雾和水意。
- 当前段和关键节点周边视觉密度高于 A 版。
- 偏航重规划时继续降低主线装饰透明度，在临时路线附近显示青蓝雾气提示。
- 重规划线、当前位置、下一站和 POI marker 的视觉优先级保持最高。
- B 版使用更多 Kenney Foliage Pack 和 Lotus Flowers PNG，但仍不使用固定屏幕大图层。

## 5. 当前限制

- 外部素材目前只选用小型 PNG，不引入大型 GLB。
- 外部素材只用于地图锚定 marker，不作为固定屏幕覆盖层。
- `debugDecor=1` 会按当前视觉变体使用独立 localStorage key，避免污染默认页。
- A/B 均未修改 `/map`、`/scenic-3d-map`、routeGeometry、roadNetwork 或腾讯 walking route 算法。
- 后续如果继续增加素材，需要先更新许可证记录。
