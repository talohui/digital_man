## 文档维护规则(避免后续脱节)

1. **改业务/功能** → 同步 `01_业务总览.md` 或 `03_功能清单.md`
2. **改架构/技术栈** → 同步 `02_技术架构.md`
3. **跑了新性能测试** → 更新 `04_性能与指标.md`(注明日期 + 测试方法)
4. **演示流程调整** → 改 `05_答辩演示脚本.md`
5. **改部署/环境** → 改 `SETUP.md`,**不要**写进上面 5 篇
