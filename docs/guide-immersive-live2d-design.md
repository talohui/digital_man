# 沉浸式 Live2D 数字人导览页设计

## 目标

把 `/guide` 重构为参考图风格的沉浸式数字人导览台：现有可交互、可口型同步的 Live2D 成为整屏主视觉，聊天与导览控制以轻量浮层呈现。

## 回退与保留

- 当前 `HomePage` 的功能与布局完整保留在 `/guide/classic`。
- 新的 `/guide` 为沉浸式默认页，右上角提供“经典布局”入口。
- 经典页增加“沉浸导览”入口，随时来回切换。
- 路线推荐、游客偏好、QuickAsks、ChatPanel、Fay/RAG 会话和 Live2D 音频口型链路均继续复用现有组件与状态。

## 视觉方向

采用“移动端导览台”而不是仪表盘：浅青蓝天空、柔和山影和低对比光晕构成背景；Live2D 位于中轴并放大至主要可视区域。界面前景只保留必要信息：当前位置/导览状态、两条示例对话气泡、底部主语音按钮、景区介绍与路线入口。

## 布局

```text
顶部：返回 / 标题 / 经典布局
中部：大尺寸 Live2D（背景主角）
左上：当前导览状态
右侧：实时回复气泡
底部：景区介绍、语音主按钮、路线入口
底部抽屉：完整文本聊天、偏好与路线推荐
```

桌面端保留相同层级，但将控制区限制在内容宽度内，避免 Live2D 被拉伸或遮挡。

## 组件边界

- 新增 `GuideImmersivePage`：只负责场景布局、浮层状态与经典页切换入口。
- 复用 `Live2DStage`：不改变模型、动作、口型或 Fay 状态协议。
- 复用 `ChatPanel`：放入按需打开的底部抽屉，避免常驻面板压缩人物画面。
- 复用 `QuickAsks` 与路线推荐数据：在“景区介绍/路线”抽屉中展示。

## 验证

- `/guide` 显示放大的 Live2D 主视觉，聊天浮层和语音主按钮可操作。
- `/guide/classic` 保留当前页面并可正常使用。
- 两个页面使用同一默认会话 ID，切换后聊天记录、音频状态和数字人状态不断开。
- 在移动端与桌面端检查人物不被遮挡、按钮可点、文字不溢出。
