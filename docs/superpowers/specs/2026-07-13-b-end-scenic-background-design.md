# B 端灵山水彩背景替换设计

## 目标

使用用户提供的灵山水彩全景图替换 B 端右侧工作区现有米黄色纯色背景，增强灵山胜境的文化辨识度，同时保持运营数据、图表、表格和操作按钮的清晰度。左侧墨绿色导航及所有真实功能保持不变。

## 视觉方案

- 强度采用用户确认的“中等显现”：景区山体、建筑群和右侧造像可以辨认，但不与数据争夺注意力。
- 图片只作用于 `.admin-ops-workspace`，不得影响游客端、登录页或左侧导航。
- 背景以右侧重要造像为视觉锚点，桌面端采用偏右居中的裁切位置，铺满工作区且不重复。
- 图片上覆盖暖白色双阶段遮罩：上方略透、内容密集区域略实，使首屏仍有文化氛围，长页面保持阅读稳定。
- 不叠加新的网格、祥云、莲花或金色装饰，避免文化元素相互竞争。

## 内容可读性

- 顶部栏使用高不透明度暖白背景，维持导航、服务状态和按钮的对比度。
- 数据卡、表格和图表容器保持暖白材质，背景不透明度控制在约 92% 至 97%，不把整页改成玻璃拟态。
- 运营摘要等重点面板可保留少量暖金色调，但文字、图表坐标轴和状态色不调整数据语义。
- 任何区域不得因背景图产生低对比文字、图表线条丢失或按钮边界不清。

## 资源与实现边界

- 原图复制到 `demo/public/images/admin/lingshan-ops-landscape.png`，不引用聊天临时目录。
- 新样式仅写入 `demo/src/styles/admin-ops.css`，使用 `.admin-ops-shell` 或 `.admin-ops-workspace` 作用域。
- 不修改 API、路由、数据结构、图表配置或页面业务逻辑。
- 不新增图片处理依赖；保留原始分辨率，浏览器负责 `cover` 裁切。

## 响应式策略

- 桌面端使用铺满工作区的固定视觉背景，优先保留右侧造像与中央建筑轴线。
- 窄屏取消固定背景附件，避免移动浏览器滚动性能问题；使用更强遮罩并将焦点移向中央建筑区域。
- 左侧导航展开、收起以及 390px 窄屏菜单打开时，背景不得出现横向溢出或跳动。

## 验收标准

1. `/admin` 及所有 `/admin/*` 页面右侧均显示同一灵山水彩背景。
2. 左侧墨绿色导航不受图片影响。
3. 1280px 与 1440px 桌面宽度下可辨认灵山景观，同时所有数据清晰可读。
4. 390px 窄屏无横向溢出，背景不会导致明显滚动卡顿。
5. 游客端页面不加载或显示该 B 端背景。
6. 前端完整测试和生产构建继续通过。
